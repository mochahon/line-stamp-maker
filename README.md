# スタンプメーカー（LINEスタンプ作成Webアプリ）

ブラウザだけでLINEスタンプ（静止画）を作成できる、完全クライアントサイドのWebアプリです。
アップロードした画像は端末内だけで処理され、外部サーバーへ送信されることはありません。

## 使い方

1. 「画像を追加」でイラストを読み込む（PNG / JPEG / WebP、複数可）
2. 1枚に複数のキャラクターが描かれた画像は「シートを分割」で切り分け
   （自動検出＋ドラッグで分割線を調整可能）
3. スタンプをタップして編集
   - 背景透過（強さ調整つき）／消しゴム／復元ブラシ
   - 余白カット、移動・ピンチ拡大縮小・回転、元に戻す／やり直す
   - 文字入れ（フォント・色・縁取り・影・縦書き・回転、セリフのテンプレート）
4. 「プレビュー」でLINEのトーク画面風に確認（明／暗背景）
5. 「出力」で自動チェックを確認し、LINE申請用ZIPを保存
   - ZIPの中身：`01.png`〜（スタンプ）、`main.png`（240×240）、`tab.png`（96×74）
6. LINE Creators Market にZIPをアップロードして申請

編集データは端末の IndexedDB に自動保存されます（アプリを閉じても復元可能）。
「出力」画面からプロジェクトのバックアップ（JSON）を書き出し／読み込みもできます。

## iPhone / iPad へのインストール

Safariで開く → 共有ボタン → 「ホーム画面に追加」。全画面（スタンドアロン）で起動でき、
初回読み込み後はオフラインでも編集・保存・ZIP出力が使えます。

## LINE公式規格への対応（静止画スタンプ）

LINE Creators Market 制作ガイドライン（2026年11月確認）に準拠しています。

- スタンプ画像：最大 370×320px、縦横は偶数px、PNG、背景透過、1個 1MB 以下
- 個数：8 / 16 / 24 / 32 / 40 個
- メイン画像：240×240px、タブ画像：96×74px
- イラスト周囲の余白は約10pxを推奨（自動チェックで警告表示）
- ZIP全体 60MB 以下

## 技術構成

- 静的サイトのみ（GitHub Pages で無料公開可能、相対パスでサブディレクトリ対応）
- 依存ライブラリなし：Canvas API / IndexedDB / Service Worker など標準Web技術のみ
  - ZIP生成も自前の軽量実装（STORE形式、PNGは再圧縮しないため劣化なし）
- フォント：M PLUS Rounded 1c、Yomogi（SIL Open Font License 1.1、Google Fonts から配信し
  Service Worker でキャッシュするため、2回目以降はオフラインでも利用可能）
- 元のイラストをAIで描き直す処理は行いません。透過・切り抜き・文字合成のみです

## メンテナンス

- アプリを更新したら `sw.js` の `VERSION` を上げてください（例：`v1` → `v2`）。
  ユーザー側では「新しいバージョンがあります」という通知が出て、更新しても編集中の
  データ（IndexedDB）は保持されます。
- アイコンは `tools/make_icons.py`（Pillow）で再生成できます。
